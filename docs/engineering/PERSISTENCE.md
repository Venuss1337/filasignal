# Controller persistence

For the Fabric adapter, see [Programmable Computer lifecycle and persistence](../minecraft/COMPUTER-PERSISTENCE.md).

`Interpreter.snapshotGlobals()` builds a complete state document while the runtime is idle. `restoreGlobals(bytes, migration)` supplies saved data before the first successful activation. The standalone simulator can load and save through a `StateStore` keyed by controller identity. Call `Controller.save()` at the chosen safe point. A store must atomically replace the previous snapshot on successful save. Storage I/O is a host responsibility.

Format version 1 starts with the FSGS signature and version, then named global roots with their annotations, a tagged value table with local reference IDs, and a CRC32 checksum for accidental corruption. Strict UTF-8 encodes strings and names. The codec supports scalars, explicit errors, lists, tuples, insertion-ordered dictionaries, enum values and class instances. Aliases and cycles through mutable values survive a restart, including cycles that involve tuples. Restoration validates references and rejects impossible immutable tuple cycles. Snapshots are limited to 262,144 bytes and 16,384 values. Each collection has the normal 4,096-entry limit. Java objects, function metadata, namespaces, event queues, local variables and runtime budgets have no persisted representation.

Saved values with compatible annotations take precedence over defaults. Added globals use their initializers. Removed or renamed globals, changed global annotations, missing enum members, and changes to ordered class fields or field annotations fail activation. Constructors and field initializers do not run when rebuilding saved instances. Method changes can reuse compatible field state. The optional trusted migration callback receives the original incompatible snapshot and its reason. Its replacement is checked against the current schema. Corruption and truncation fail separately. Neither incompatible data nor failed activation causes an automatic overwrite or reset.
