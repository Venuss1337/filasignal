# Name and branding

This page is about the project's name and identity. It does not limit any right the
[GNU General Public License v3.0](../LICENSE) gives you over the code and assets.

## The official project

The official FilaSignal project is the repository at https://github.com/Venuss1337/filasignal, its releases, and
the documentation at https://venuss1337.github.io/filasignal/. Platform listings (such as Modrinth or CurseForge)
are official only when they are linked from that repository.

## Using the name

You may use "FilaSignal" and "FilaScript" to refer to the project truthfully: to say that your mod, server, program,
video or tool works with, uses or is based on FilaSignal, and to credit it.

If you distribute a modified version, please make that clear: give it a different name or mark it plainly as
unofficial (for example "MyPack edition, based on FilaSignal"), and do not present it as an official FilaSignal
release or imply that the FilaSignal maintainers support it. Use a different mod ID if your changes alter saved data
or networking, so players do not confuse it with official releases.

These are requests about identity, not extra license conditions. "FilaSignal" is not a registered trademark.

## Logos and artwork

The project has no separate logo. Block and item textures and the documentation's images are part of the repository
and covered by its license, except for Minecraft's own content in screenshots, which belongs to Mojang Studios.
