# Community Code of Conduct

The goal is productive, technically rigorous collaboration. Everyone participating in FilaSignal's issues, pull requests and community spaces is expected to:

- Communicate respectfully; critique ideas and code rather than people.
- Avoid harassment, threats, hate speech, personal attacks, unsolicited sexual content and disclosure of private information.
- Give clear, actionable feedback. Disagreeing about implementation decisions is welcome; hostility is not.
- Respect licenses, attribution, ownership and community safety.
- Avoid spam, repeated disruptive behavior and misleading security reports.

Project maintainers may edit or remove abusive content, restrict participation, or exclude repeat offenders. Decisions should be proportionate and should consider evidence and context.

For misconduct, use GitHub's "Report content" option on the issue, comment or user involved, or contact the maintainer through GitHub. For vulnerabilities, follow `SECURITY.md` instead of opening an issue containing exploit details.
