title: Tutorials
description: Step-by-step FilaSignal projects from your first program to autonomous networks of cooperating devices.
---

Each tutorial lists the hardware it needs, how to connect it, where each program goes and the complete program. Every
program on these pages is checked against the mod's real API.

If you have never used FilaSignal, start with [your first automation](/minecraft/getting-started/first-automation/).
To learn the language itself, see [FilaScript](/language/).

| [Weather display](/minecraft/tutorials/beginner/weather-display/) | A screen that shows the weather. |
