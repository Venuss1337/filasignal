An outpost 200 blocks away is too far for links. A pair of [Wireless Network Bridges](/minecraft/hardware/wireless-bridge/)
joins it to your network.

**You need:** a computer, two Wireless Network Bridges, an Entity Detector named `outpost` and an Alarm Module named
`outpost_alarm`.

## Build

1. Place one bridge near the computer, link the computer to it and name it `link`.
2. Travel to the outpost, at most 256 blocks away in the same dimension, and place the second bridge.
3. Place the detector and the alarm there, link both to the far bridge and name them.
4. Open either bridge's form. It lists your unpaired, loaded bridges in range. Choose the other one and select
   **Pair**. Both areas must be loaded while pairing, so pair from the outpost, before walking home if needed.

## How it works

- To the program, the outpost devices are ordinary network devices: the bridges are invisible.
- When you walk home, the outpost's area unloads. Its devices become unreachable and `disconnected` runs. When you go
  back, `connected` runs. Bridges never keep chunks loaded.
- `link.status()` reports the pairing and the distance.

## Keep the outpost working while you are away

While the outpost is unloaded, nothing there runs. While it is loaded but your home is not, a computer program cannot
run either, but an [autonomous alarm](/minecraft/guides/autonomous-devices/#an-autonomous-alarm) at the outpost keeps
working.
