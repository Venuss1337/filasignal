FilaSignal is a Minecraft mod for automation you program yourself. You craft a **Programmable Computer** and
**devices** such as detectors, alarms, displays and redstone controllers, connect them into a network, and write short
programs that decide what happens.

## What can you build?

- An **intruder alarm** that sounds when a hostile mob walks up to your base.
- **Night lights** that switch on at sunset and off at sunrise.
- A **weather board** that shows the weather on a screen.
- A **door** that opens only for your friends, without any program at all.
- A **storage monitor** that warns you when the iron in a chest runs low.
- A whole **security network** where devices keep working even while you are far away.

<Steps>

1. **Hardware.** Every device is a block with one job: seeing entities, reading the weather, sounding an alarm,
   showing text. See the [hardware list](/minecraft/hardware/).
2. **Network.** The Linking Tool connects the computer to a relay, such as a Network Repeater, and the relay to each
   device. You give each device a name, such as `gate`.
3. **Program.** On the computer you write a program in [FilaScript](/language/). It refers to devices by name and
   reacts to their events:

   ```fsig
   const gate = detectors.named("gate")
   const siren = alarms.named("siren")

   on gate.entityEnter(entity) {
       siren.activate()
   }
   ```

4. **Autonomy, later.** A device with a Programmable Data Drive runs its own program, so it keeps working even when
   the computer's area is not loaded. See [autonomous devices](/minecraft/guides/autonomous-devices/).

</Steps>
