every event.

`on timer.every(ticks)` needs a whole number of ticks, at least 1. Ticks that pass while a program is paused by the
debugger are skipped.

## Device events

Use a device constant: `const gate = detectors.named("gate")`, then `on gate.entityEnter(entity) { … }`. A drive
program handles its own device's events as `on device.entityEnter(entity) { … }`.

## Drive program events

A drive program on a Redstone Controller can also use the older `on redstone.rising("north")`, `redstone.falling` and
`redstone.changed` for its own sides, and every drive program can handle `events.custom`.

## Delivery

| Rule | Detail |
| --- | --- |
| Sampled | Entity Detector every 10 ticks; Weather Station, Environment Sensor and Inventory Module every 20; only while listened to; at most 32 devices sampled per tick. |
| Immediate | Redstone, Alarm, Access Controller and Control Panel events. |
| Baseline | The first reading after a program starts sets the baseline; it raises no events. |
| Queue | Each program queues at most 32 events. Extra events are dropped and counted. |
| Order | One handler per program per tick, never while another handler of that program runs. |
| Reach | Computers: loaded devices connected to the computer. Drive programs: loaded devices of the same network connected to them through loaded devices. |
| Values | Copied for every handler. Lists, tuples and dictionaries at most 8 levels, 512 values, 16,384 characters. |
