Every device's methods in one place. The [hardware pages](/minecraft/hardware/) explain each device with examples.
Call methods on a reference or handle, such as `gate.count(Entity.HOSTILE)`. In a drive program, call the device's own
methods on `device`, such as `device.count(Entity.HOSTILE)`.
