## Easy things are easy

This is a complete program. When something walks up to the detector named `gate`, the alarm named `siren` sounds:

```fsig
const gate = detectors.named("gate")
const siren = alarms.named("siren")

on gate.entityEnter(entity) {
    siren.activate()
}
```

## Complex things are possible

Devices can run their own programs from data drives, keep working while the computer is far away, share data on a
Storage Server and talk to each other with custom events. See the [advanced tutorials](/minecraft/tutorials/#advanced).
