# Documentation site

- Astro + Starlight with Bun 1.4.4: `bun install --frozen-lockfile`, `bun --bun run dev`, `bun --bun run build` (the
  build also runs `scripts/check-site.ts`: links, anchors, base path, search index). Local Node may be too old; use Bun.
- Two areas with separate sidebars: `src/content/docs/language/` (standalone FilaScript, no Minecraft) and
  `src/content/docs/minecraft/` (the mod). Keep them separate.
- The site is served under `/filasignal/`. Write internal links as `/minecraft/...`; the base is added by a plugin.
- `src/data/generated/minecraft-api.json` is generated by the GameTests; never edit it by hand.
- Code blocks with `fsig` are tested: language examples run in core tests, Minecraft examples (```` ```fsig target="..." ````)
  are resolved against the mod's registries. Screenshots in `public/screenshots/` must be real in-game captures.
